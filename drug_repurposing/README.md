# Drug Repurposing

This folder contains scripts and results for drug–target interaction prediction using pretrained DeepPurpose models.

## Method
- Deep learning-based prediction (DeepPurpose)
- Drug ranking based on predicted interaction scores
- Blood–brain barrier (BBB) filtering

## Purpose
To identify candidate drugs targeting autism-associated hub genes.

## Applicability to Autism Subtypes
The same predictive framework is applied to both syndromic and idiopathic autism gene sets, enabling subtype-specific drug prioritization.
