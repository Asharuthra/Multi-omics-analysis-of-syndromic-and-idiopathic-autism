# miRNA Analysis

This folder contains scripts for constructing and analyzing miRNA–hub gene regulatory networks.

## Data Sources
- miRTarBase
- TarBase
- miRmine (brain-specific filtering)

## Purpose
To identify miRNA-mediated regulatory interactions associated with autism subtypes.

## Applicability to Autism Subtypes
The workflow is applied uniformly to both syndromic and idiopathic autism gene sets, enabling subtype-specific regulatory network analysis.This folder contains scripts for miRNA–hub gene regulatory network analysis and filtering.
