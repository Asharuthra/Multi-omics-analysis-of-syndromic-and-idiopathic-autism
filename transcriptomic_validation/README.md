# Transcriptomic Validation

This folder contains scripts used to analyze gene expression patterns of autism-associated hub genes across brain regions and cell types.

## Data Sources
- GTEx (bulk tissue transcriptomics)
- Human Protein Atlas (tissue-specific expression)
- Allen Brain Atlas (single-cell RNA-seq)

## Purpose
To validate subtype-specific hub genes by examining their spatial and cell-type–specific expression in the human brain.

## Applicability to Autism Subtypes
The same scripts are applied to both syndromic and idiopathic autism gene sets. Subtype-specific results are generated based on the input gene lists.
